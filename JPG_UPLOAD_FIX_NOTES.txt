JPG UPLOAD FIX - v6

- JPG/JPEG is selected directly from the Super Admin panel.
- Browser sends the image as JSON/base64.
- Server validates JPG bytes and 5 MB maximum size.
- When Supabase is configured, the server uploads the JPG to the Supabase
  Storage bucket and returns a permanent public URL.
- Movie data, votes, voting status, week label, and poster URLs are stored in
  Supabase table public.site_data, so Render Free restarts do not erase them.
- Without Supabase environment variables, the app falls back to local storage;
  that fallback is NOT permanent on Render Free.
