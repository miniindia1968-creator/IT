ANANT VIJAY VOTING V2 — RENDER SETUP

1. Create a Render Web Service from this folder/repository.
2. Build command: npm install
3. Start command: npm start
4. Environment variables:
   ADMIN_PASSWORD = your private admin password
   ADMIN_SECRET = a long random secret string
   DATA_DIR = /var/data   (recommended only if you attach a Render persistent disk)
5. IMPORTANT: This version uploads JPG/JPEG using multipart/form-data and returns JSON from every API route.
6. The website and API are on the SAME Web Service, so the upload does not depend on a separate Netlify/Render function.
7. For permanent uploaded posters across Render restarts/redeploys, attach a persistent disk and set DATA_DIR=/var/data. Mount the disk at /var/data. Without a persistent disk, Render's free filesystem can reset after restarts/redeploys.
8. No public voting results are shown on the user website; results are visible only to Super Admin.
